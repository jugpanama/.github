## Welcome to Panama Java User Group

**Panama Java User Group (Panama JUG)** is the meeting point for the
**Java and JVM community** in our country — a space to **connect,
learn, and collaborate** among developers and professionals across the
Java enterprise ecosystem.

As part of the **global network of Java User Groups**, we promote
knowledge of the modern Java ecosystem — Jakarta EE, MicroProfile,
Spring, Quarkus, and more — share resources, and build a stronger
community for everyone interested in the Java platform in Panama.

---

### Our Mission

Our mission is to strengthen the tech ecosystem in Panama by providing
a space to **expand Java enterprise knowledge**, boost local talent,
and inspire application modernization.

We achieve this by hosting talks with local and international experts,
virtual and in-person meetups, and hands-on sessions on
**Jakarta EE, Java EE migration, enterprise architectures, and cloud native**.

---

### What you will find in this organization

We use GitHub as our technical hub. Here is how you can participate:

* 💬 **Discussions & proposals:** The heart of our community. Join the
  conversation to ask questions, share solutions, or propose topics for
  future meetups.
* 📅 **Events & workshops:** Access resources, code samples, and slides
  from our sessions on **Jakarta EE, Java EE migration, enterprise
  architectures, and cloud native**.
* 🤝 **Networking:** A space to connect with passionate engineers, grow
  your professional network, and find mentorship opportunities.

### Get Involved!

We are a volunteer-driven organization and we want to hear from you.
The best way to start is:

1. Follow us on **[LinkedIn](https://www.linkedin.com/company/panamajug/)**
2. Subscribe to our **[YouTube Channel](https://www.youtube.com/@jugpanama)**
3. Visit our website at **[panamajug.org](https://panamajug.org)**
4. Submit a talk for our next meetup! You can send your proposal for
   virtual or in-person sessions through our CFP:
   [https://sessionize.com/panama-jug-2026](https://sessionize.com/panama-jug-2026)
