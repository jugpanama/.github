# Panama Java User Group (Panama JUG) 🇵🇦

El **Panama Java User Group (Panama JUG)** es el punto de encuentro de la comunidad Java y la JVM en nuestro país. Operamos como un espacio de ingeniería de alto rendimiento para conectar, aprender y colaborar entre desarrolladores y tomadores de decisiones del ecosistema empresarial.

Promovemos el conocimiento del ecosistema Java moderno (Jakarta EE, MicroProfile, Spring, Quarkus, Helidon y demas) con un enfoque en implementaciones reales, arquitectura Cloud Native y retorno de inversión para el sector bancario, logístico y corporativo de Panamá.

---

## International Visitors & Open Source Partners

The Panama Java User Group is an independent community focused on advancing the Java ecosystem in Panama through open standards under permissive licenses. 

* **Our Goal:** We are actively preparing to join the **"Adopt-a-Spec"** program by the Eclipse Foundation to contribute directly to the evolution of Jakarta EE.
* **Language Policy:** While our day-to-day operations and community governance are in Spanish to serve our local ecosystem and banking sector, our code-centric repositories, TCK tests, and starter projects are maintained in English to ensure global collaboration. Feel free to open issues or pull requests in English!

---

## Nuestra Misión

Nuestra misión es fortalecer el ecosistema tecnológico en Panamá proporcionando un espacio riguroso para **expandir el conocimiento de Java empresarial**, impulsar el talento local y certificar de facto la calidad técnica de nuestros miembros.

No vendemos tendencias pasajeras. Hablamos de código en producción, modernización de sistemas legacy a arquitecturas modernas y entrega de valor real a las organizaciones.

---

## Neutralidad e Independencia Tecnológica

El Panama JUG no es el brazo de marketing de ningún proveedor (vendor). Tratamos todas las implementaciones (Helidon, Quarkus, Payara, Spring, Open Liberty, etc.) como alternativas de ingeniería válidas sujetas a evaluación técnica y de negocio. Nuestro foco principal son los estándares abiertos.

---

## Liderazgo de la Comunidad

El Panama JUG es liderado por profesionales de la industria comprometidos con la construcción de una comunidad técnica activa y de alto nivel en el país.
